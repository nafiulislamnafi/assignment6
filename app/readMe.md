
**Project Name**

FitLog — Workout Library & Planner

**Descrioption**
FitLog is a modern, responsive workout management website built with Next.js and TypeScript. Users can browse workouts from an API, view detailed workout information, add exercises to their daily plan, save workouts for later, and track completed exercises.

**Technologies Used**
Next.js — App Router, routing, dynamic routes, Server & Client Components
React — Components, Props, State, Hooks, Event Handling, Conditional Rendering
TypeScript — Type-safe workout data and components
Tailwind CSS — Responsive and modern UI styling
Context API — Global management of Today's Plan, Saved workouts, and completed workouts
REST API / JSON — Fetching workout data from the FitLog API
React-Toastify — Toast notifications for user actions


*Key Features*
1.  Workout Library

2. Today's Plan

3.  Save Workouts

4.  Dynamic Workout Details

5. Workout Management
